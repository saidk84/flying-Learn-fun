# Flying: Learn & Fun

An offline-first Android learning game for curious young pilots. Choose drones, jets, and other aircraft, explore aviation topics, and steer through three-lane flight missions to collect spoken targets.

## Mobile game

The game is designed for Android as a self-contained WebView app. Gameplay, learning content, and generated audio can run offline. The browser version is also available from the repository root once packaged.

## Game features

- Aircraft hangar with drones, propeller planes, passenger jets, helicopters, and more.
- Learn & play routes for aircraft, sky and weather, aviation basics, numbers, and colors.
- Three-lane flight missions using touch, swipe, or arrow controls.
- Spoken target prompts, progressive levels, stars, combos, and free flight.
- Child-friendly rounded cards, pastel visuals, and local progress saving.

This project follows the interface and learning-game structure of [Racing: Learn & Fun](https://github.com/saidk84/racing-Learn-Fun), reimagined around aviation.
